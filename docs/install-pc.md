# 💻 Install on PC / Instalación en PC

---

## 🇬🇧 English

Works on any Chromium-based browser: Chrome, Edge, Brave, Opera, Vivaldi.

### Step 1 — Download the ZIP

Go to [Releases](../../releases) and download `XBoost.zip`.

![Download ZIP](../images/pc/01-download-zip.png)

### Step 2 — Extract the file

> ⚠️ **VERY IMPORTANT:** Chrome does not load ZIPs directly. **You must extract it first.**

Right-click the ZIP → **"Extract All..."** (Windows) or double-click (Mac).

![Extract](../images/pc/02-extract.png)

You'll get a folder named `XBoost` with all the files.
